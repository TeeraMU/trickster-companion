# สเตตัสตัวละคร

## เป้าหมาย

แสดงค่าแบบ `AP base (+equipment)` โดยแยกบัฟและแหล่งที่มาให้ตรวจได้ ค่าหน้าต้องประกอบด้วย **ค่าตั้งต้น + Growth + Bonus Points** ตามกติกาที่ตรวจแล้ว ส่วนในวงเล็บเป็นโบนัสจากไอเทม รวมการปรับแต่งที่เกี่ยวข้อง

## สิ่งที่มีและยังไม่ยืนยัน

- `js/build.js` / `data/builds.json` มีสูตรเดิมสำหรับส่วนเพิ่มจาก Growth และ Bonus Points แต่ยังไม่รวมค่าตั้งต้นหรืออุปกรณ์ และอ้างอิงข้อมูลเก่า
- การตรวจตารางที่แกะมาพบข้อมูลตัวละครและ UI แต่ยังไม่พบตารางที่ยืนยันค่าตั้งต้นและสูตรครบทุกอาชีพโดยตรง
- เดโมปัจจุบันแสดงเฉพาะ Growth ตัดทศนิยมเพื่ออ่านง่าย เป็นสมมติฐานชั่วคราว ยังไม่ใช่ Base Stat ครบและยังไม่ยืนยันกฎปัดของเกม
- หลักฐานตัวอย่าง Cat / Primadonna Lv.152 Growth 4-1-1-4 และรายละเอียดเปรียบเทียบอยู่ใน `planner-demo/STAT_CHECK.md` ภาพหนึ่งมี AP stat level 300 จึงไม่ใช่ Growth ตามเลเวลอย่างเดียว

## งานตรวจและรับรอง

1. ตรวจค่าเริ่มต้นตามตัวละคร / อาชีพและเลเวลสเตตัส เรียนรู้หน่วยของ Growth ticks กับ Bonus Points และจุดปัดของแต่ละค่า
2. เก็บตัวอย่างหลายอาชีพ หลายเลเวล หลาย Growth ก่อน / หลังลง Bonus และก่อน / หลังสวมไอเทม; เก็บที่มาและผลจริงที่ทำซ้ำได้
3. แยกสูตรและชุดข้อมูลตามเวอร์ชันเกมเมื่อจำเป็น เพิ่มชุดทดสอบจากตัวอย่างจริงก่อนแสดงค่าที่เชื่อถือได้
4. ยังคงแยกค่า Growth ที่ไม่สมบูรณ์ออกจาก Base Stat จริง และแสดงส่วนที่ยังไม่ทราบ
