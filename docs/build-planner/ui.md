# UI และการใช้งาน

## หน้าหลัก

- แยก Build Guide ที่เน้นอ่านออกจาก Build Planner ที่เน้นทดลอง โดยมีปุ่มเชื่อมไปมาพร้อมส่งอาชีพที่เลือก
- จุดสำคัญที่สุดคือเห็นว่า **บิลด์นี้ใส่อะไร** และ **ผลต่อบอสเป็นอย่างไร**: เดสก์ท็อปให้อุปกรณ์อยู่ด้านซ้าย Battle Summary อยู่ด้านขวาใกล้สรุปสเตตัส; มือถือเรียงเป็นส่วนที่เข้าถึงง่ายโดยไม่ซ่อนข้อมูลสำคัญ
- แสดงอุปกรณ์รอบตัวละครตามหน้าต่างเกม: หู หาง เสื้อชั้นใน สัตว์เลี้ยง ผ้าคลุม และ Fashion สองช่องที่มีสเตตัส รวมทั้งช่องหลักอื่น ตรวจตำแหน่ง / ประเภทกับเกมก่อนสรุป
- ให้ผู้ใช้เห็นชื่อไอเทมที่สวมและเข้าถึงรายละเอียด / ปรับแต่งแต่ละช่องได้ รองรับคีย์บอร์ดและหน้าจอสัมผัส
- แสดงสเตตัสตัวละครแยกโบนัสจากไอเทมและบัฟ โดยไม่เรียกค่า Growth อย่างเดียวว่า Base Stat ที่ครบแล้ว

## เปรียบเทียบ

- ชี้ hover / โฟกัสด้วยคีย์บอร์ดเพื่อดูไอเทมใหม่เทียบของเดิม; บนมือถือมีการแตะดูได้โดยไม่บังคับใส่ไอเทม
- มีพื้นที่เทียบทั้งเซ็ต A/B แยกรายการช่องที่เปลี่ยนและผลต่างรวม โดยชุดทดลองไม่แก้ชุดหลักจนเลือกนำไปใช้
- แสดงชัดว่าเทียบรวม Refine, Compound, ค่าสุ่ม, ธาตุ, บัฟ และเงื่อนไขใดแล้ว / ยังไม่รวม

## สกิล บัฟ และบอส

- ตัวเลือกสกิลจัดกลุ่มสกิลและเลเวล รวม Master เมื่อยืนยันความหมายของข้อมูลได้
- Buff Config แยกจากสกิลโจมตี โดยติ๊กหลายบัฟและเลือกระดับได้ ดู [skills-buffs.md](skills-buffs.md)
- Battle Summary มีรูปมอนสเตอร์ สกิล มอนสเตอร์ สเตตัส ธาตุ ผลดาเมจ และที่มาของตัวเลข ดู [monsters-battle.md](monsters-battle.md)
- ข้อมูลที่ไม่ทราบให้แสดงว่าไม่ทราบ / รอตรวจ พร้อมที่มา แทนค่าที่ดูเหมือนแม่นยำ

## สิ่งที่เดโมมี / ยังขาด

เดโมแสดงช่องรอบตัวละคร มีการเปรียบเทียบค่าพื้นฐาน บัฟกรอกเอง และ Battle Summary ทดลองแบบคูณค่าด้วยมือ การแสดงรูปและสเตตัสบอสยังไม่ครบและยังไม่คำนวณดาเมจจริง ต้องทบทวน layout และทดสอบมือถือ / เดสก์ท็อปก่อนนำขึ้นเว็บจริง
