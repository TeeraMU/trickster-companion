# อุปกรณ์และข้อมูล custom

## แหล่งข้อมูลตั้งต้น

- ใช้ข้อมูลที่แกะจาก `G:/Claude/playtrickster-extraction` เป็นฐานเริ่มต้น ตารางหลัก `ItemParam2`, `ItemParamCM2`, `ItemParamEx`, `ItemParamEx2` รวม 33,385 แถว ไฟล์รวมอยู่ที่ `item-catalog/all-items.json`
- `Class = 2` และการจับคู่ Type กับช่องในเดโมเป็นตัวกรองเบื้องต้น ไม่ยืนยันว่าเป็นรายการที่สวมได้จริงทั้งหมด หรืออยู่ในเกมใหม่ทั้งหมด ต้องตรวจ ID, ประเภท, เลเวล, อาชีพ, เซิร์ฟเวอร์ และความพร้อมใช้งาน
- `Item_Attribute` เชื่อมกับไอเทมด้วย ID และมีค่าธาตุ แยกโจมตีธาตุออกจากต้านทาน เช่น `Fire` และ `FireR`; ตรวจหน่วยและวิธีใช้กับเกมใหม่ก่อนนำเข้าการคำนวณจริง
- White Swan Staff ใน client เดิม ID 75821 มีบางค่าตรงภาพเกมใหม่ แต่ยังไม่ยืนยัน ID ข้าม client; Fierce Wind Ring ได้ค่าจากภาพ ยังไม่รู้ว่าเป็นค่าพื้นฐานหรือผ่านการปรับแต่ง

## รูปแบบข้อมูล

- แยกข้อมูลไอเทมกลาง เช่น ID, ชื่อ, ชนิด, ช่อง, ข้อกำหนด, ค่าพื้นฐาน, ธาตุ, รูป และแหล่งข้อมูล ออกจาก **อุปกรณ์แต่ละชิ้นในบิลด์**
- แต่ละชิ้นเก็บระดับ Refine, โบนัสจาก Refine, จำนวนช่อง Compound, รายการวัสดุ / สเตตัส / ค่าของแต่ละช่อง และโบนัสอื่นที่กรอกเอง
- อุปกรณ์ custom เพิ่มและแก้ชื่อ ประเภท ช่อง เลเวล สเตตัส ธาตุ และหมายเหตุได้; เก็บข้อมูล custom ไปกับบิลด์ที่แชร์เพื่อให้ผู้รับเปิดแล้วเห็นครบ
- ระบุที่มา: client เดิม, ตรวจในเกมใหม่, ผู้เล่นเพิ่มเอง / รอตรวจ; เก็บวันที่และฟิลด์ที่ยืนยันเท่าที่มี
- ไม่ทับค่าพื้นฐานด้วยค่าจากภาพของที่ผ่าน Refine / Compound และไม่จับคู่ของคนละชิ้นด้วยชื่อเพียงอย่างเดียว

## งานที่ต้องตรวจ

1. แยกประเภทและข้อจำกัดช่องตามเกมใหม่ โดยเฉพาะ Fashion สองช่อง หู หาง เสื้อชั้นใน และสัตว์เลี้ยง
2. ตรวจสูตร Refine / Compound และขอบเขตจำนวนช่อง แสดงค่าที่ผู้ใช้กรอกเองจนกว่าสูตรจะยืนยัน
3. ตรวจว่าตัวคูณธาตุจากของ สกิล และบัฟรวมกันอย่างไร รวมถึงเงื่อนไขสวมใส่ / Set bonus
4. ทำรายการแก้ไขแยกจากข้อมูลดิบและทดสอบการอัปเดตฐานโดยไม่ทำบิลด์เก่าพัง

การเทียบชื่อไอเทมในรายงานเก่าใช้เฉพาะ `ItemParam2` ต้องเทียบใหม่รวมทุกตารางก่อนใช้สรุปว่าของไม่มีในฐาน
