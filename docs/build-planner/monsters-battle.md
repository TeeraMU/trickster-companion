# มอนสเตอร์และ Battle Summary

## หน้าทดลองต่อสู้

- เลือกมอนสเตอร์ / บอสและสกิลพร้อมระดับ แสดงรูปมอนสเตอร์ ชื่อ เลเวล และที่มาข้อมูล
- สรุป HP, DP, MD, ธาตุ / ความต้านทาน และข้อมูลอื่นเมื่อยืนยันความหมายแล้ว; หากไม่มีรูปหรือค่าให้แสดงว่ายังไม่มี / รอตรวจ
- สรุปสกิล ประเภทการโจมตี ธาตุ ตัวคูณสกิล สเตตัสที่ใช้ บัฟ และตัวคูณธาตุของผู้เล่น / มอนสเตอร์ พร้อมแหล่งที่มาทีละส่วน
- แสดงดาเมจ / DPS / จำนวนครั้งที่ต้องโจมตีเฉพาะกรณีสูตรและข้อมูลที่จำเป็นพร้อม ระบุขั้นตอนและสิ่งที่ยังไม่รวม; รองรับเทียบเซ็ต A/B โดยไม่เปลี่ยนบิลด์หลัก

## ข้อมูลตั้งต้นและข้อจำกัด

- เดโมใช้บอสตัวอย่าง 8 ตัวจาก `MonsterParamEx2`: Tombeth, Captain Skull, Pirate King Karan, Count Blood, Tenter Lion, Queen Odinea, Soki, Spicy Dragon แต่ละชื่ออาจมีหลาย ID / เวอร์ชัน ต้องตรวจว่าตรงตัวที่ผู้เล่นต่อสู้จริง
- ฟิลด์ `MaxHpLv`, `DpLv`, `MdLv` เป็นค่าดิบ ยังไม่ยืนยันว่าเท่ากับ HP / DEF ที่แสดงจริง และธาตุ / resistance ของเกมใหม่ยังต้องตรวจ
- เดโมปัจจุบันมีรูปตัวอย่าง Tombeth และ placeholder สำหรับบอสที่ยังไม่มีรูป แสดงผลทดลอง AP × ตัวคูณที่กรอกเองก่อนป้องกัน บอสที่เลือกยังไม่เปลี่ยนผลทดลอง; ไม่ใช่ดาเมจจริง
- ธาตุผู้เล่น: ใช้ `Item_Attribute` และค่าที่ผู้ใช้กรอกจาก Compound / บัฟที่เปิด แต่ต้องแยกธาตุโจมตีจากต้านทาน และตรวจวิธีรวมสกิล โบนัส และความสัมพันธ์กับมอนสเตอร์ก่อนคำนวณอัตโนมัติ

## การตรวจ

เก็บตัวอย่างสเตตัสจริงของบอสและผลโจมตีหลายครั้ง แยกกรณีมี / ไม่มีบัฟ ธาตุ อุปกรณ์ และสกิล ตรวจความแปรผัน การปัด และแหล่งข้อมูล แล้วทำ test cases พร้อมเวอร์ชันเซิร์ฟเวอร์ก่อนระบุว่าผลเชื่อถือได้
