# Build Planner — สารบัญแผน

อัปเดต 2026-11-20 · แผนและข้อเสนอ ยังไม่ใช่ฟีเจอร์ที่ใช้งานจริง

Build Planner แยกจาก Build Guide แต่ใช้ข้อมูลกลางร่วมกัน: Guide เน้นอ่านข้อมูล ส่วน Planner ใช้จัดตัวละคร อุปกรณ์ สกิล และทดลองผลลัพธ์ เดโม `planner-demo/` เป็นงานทดลองในเครื่อง ไม่ใช่ฟีเจอร์ที่ปล่อยบนเว็บจริง

| เอกสาร | ขอบเขต |
|---|---|
| [UI และการใช้งาน](ui.md) | การจัดหน้า, ช่องอุปกรณ์, บัฟ, การเทียบของ และ Battle Summary |
| [อุปกรณ์และข้อมูล custom](equipment.md) | ฐานไอเทม, ช่องสวมใส่, Refine / Compound, ธาตุ และแหล่งข้อมูล |
| [สเตตัสตัวละคร](status.md) | Growth, Bonus Points, Base Stat, การปัด และการทดสอบกับเกม |
| [สกิลและบัฟ](skills-buffs.md) | ตารางที่แกะมา, ระดับสกิล, Buff Config และข้อจำกัดสูตร |
| [มอนสเตอร์และดาเมจ](monsters-battle.md) | บอส, ธาตุ, ค่าป้องกัน, Battle Summary และการตรวจสูตร |
| [Build Library และการบันทึก](build-library.md) | ล็อกอิน, รายการบิลด์ตามสาย / ช่วงเลเวล, การมองเห็น, validation และป้องกันบันทึกซ้ำ |
| [แผนดำเนินงานและตรวจสอบ](delivery.md) | ลำดับงาน, migration, การทดสอบ และการปล่อยใช้งาน |

เอกสาร [แผนภาพรวมเดิม](../../BUILD_PLANNER_PLAN.md) เก็บบริบทการตัดสินใจและที่มาของข้อมูล รายละเอียดรายหัวข้อให้ดูเอกสารในโฟลเดอร์นี้ หากมีข้อขัดแย้งให้อัปเดตทั้งสองส่วนให้สอดคล้องกัน

**ข้อกำหนดที่ตกลง:** เริ่มจากข้อมูลและสูตรที่ตีความได้ใน `G:/Claude/playtrickster-extraction` พร้อมรองรับอุปกรณ์ custom; ระบุแหล่งข้อมูลและสถานะการตรวจ และไม่ถือว่า client เดิมตรงกับเกมใหม่ทุกค่า

**ข้อเสนอรอเลือก:** รูปแบบสิทธิ์และการเผยแพร่ Build Library ใน [build-library.md](build-library.md) เป็นคำแนะนำเพื่อหารือ ยังไม่ถือเป็นนโยบายที่ตัดสินใจแล้ว
