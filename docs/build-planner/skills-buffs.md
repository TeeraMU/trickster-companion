# สกิลและบัฟ

## ข้อมูลสกิล

- ใช้ `SkillParam2` เชื่อม `ESAIITable` / `ESATable` จากข้อมูลที่แกะแล้ว ร่วมกับ `data/builds.json` และ `data/skill-fixes.json` โดยคง ID และแหล่งข้อมูล
- ตรวจเบื้องต้นจับคู่ชื่อสกิลเว็บได้ 227 ชื่อ: มีชื่อตาราง ESAII 207 และ ESAction 214 ซึ่งพบไฟล์ตามชื่อครบ การจับคู่ชื่อ / หน่วย / ความหมายแต่ละฟิลด์ยังต้องตรวจ
- แสดงค่า MP, Cooldown, Range และค่ารายเลเวลที่ยืนยันความหมายแล้ว; ค่า `Ratio` ดิบไม่ยืนยันว่าสูตรดาเมจจริงคืออะไร
- ตัวเลือกสกิลจัดเป็นกลุ่มชื่อและระดับ รวม Master เมื่อยืนยันการแมปเลเวลของ client เช่นระดับ 11 ได้แล้ว; ระบุสกิลที่ยังไม่มีข้อมูล
- ข้อมูลวิกิเป็นแนวทาง ไม่รันข้อความสูตรเป็นโค้ด ต้องแปลงสูตรทีละกลุ่มและเทียบกับเกมใหม่

## Buff Config

- เมื่อเลือก class / job ให้เสนอรายการบัฟที่เกี่ยวข้องอัตโนมัติ ติ๊กเปิดหลายรายการและเลือกระดับจนถึง Master ได้
- รองรับบัฟจากเพื่อน / ปาร์ตี้ต่างอาชีพ โดยแยกแหล่งของบัฟ และรองรับค่า custom เมื่อยังไม่มีสูตร
- แยกประเภทค่าบัฟคงที่ / เปอร์เซ็นต์ / ธาตุ, ระยะเวลา, เงื่อนไข, ผลทับซ้อน / ซ้อนกัน และข้อจำกัดเซิร์ฟเวอร์ ไม่รวมโดยเดา
- แสดงผลรวมจากบัฟแยกจากไอเทม ทั้งในสรุปสเตตัสและ Battle Summary; บันทึกค่าที่เลือกในบิลด์
- เดโมตอนนี้ให้เพิ่มชื่อและกรอกค่าบัฟเอง ยังไม่ดึงบัฟตามอาชีพและยังไม่คำนวณผลจากระดับสกิลอัตโนมัติ
